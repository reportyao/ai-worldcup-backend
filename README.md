# 球多多 AI 足球预测 - 后端服务

## 项目简介

这是“球多多 AI 足球预测”平台的核心后端服务，负责承载用户前端、管理后台、预测生产线、数据同步、权益订单、赛后复盘与模型评估等关键能力。后端以 **NestJS + Prisma + BullMQ** 为主体架构，通过 API 服务对外提供统一接口，通过 Worker 服务执行足球数据同步、特征计算、AI 预测生成、共识聚合、赛后评分和复盘生成等异步任务。

近期已增强了 **多结果预测支持、Lindy 结构化展示整理、竞彩自动化同步修复、世界杯人格测试深度扩展** 能力。

## 核心能力：全自动化闭环系统

本项目已实现完整的自动化运行闭环，无需人工干预即可完成从数据抓取到 AI 预测再到结果统计的全过程。

| 能力 | 当前实现 |
| --- | --- |
| **多结果预测支持** | 系统现在支持每个预测维度（胜平负、让球、比分等）记录多个预测结果（如“主胜/平”）。命中判定逻辑已升级为“包含即命中”，极大提升了预测准确度统计的真实性。 |
| **Lindy 结构化整理** | Lindy 返回的复杂 JSON 已被自动转换为格式清晰的 Markdown（包含结论摘要、优劣势分析、风险提示等）。管理后台新增“重新提取结论”功能，可一键从历史 JSON 中重新解析预测方向。 |
| **竞彩同步修复** | 针对官方 API 的 IP 封锁问题，新增了真实浏览器 UA 轮换池和自动重试机制；同时修复了 Trade500 备用源的日期过滤与 MatchNo 提取逻辑，确保数据同步永不断线。 |
| **人格测试深度扩展** | 补充了 12 种人格的完整副标题池（每种 8 条梗文案）、战力指数、稀有度系统，并实现了与 AI PK 功能的深度联动。 |

## 主要模块

| 模块 | 当前能力 |
| --- | --- |
| **多值预测系统** | `winLossDraw` 等核心字段支持单值或数组。`evaluateAccuracy` 支持多值命中判断，只要实际赛果在预测集合中即视为命中。 |
| **Lindy 预测生产线** | 自动将 Lindy JSON 转换为结构化 Markdown 展示。管理后台 `prediction-tasks` 支持智能 JSON 格式化展示与结论重提取。 |
| **竞彩数据源** | `SportteryClient` 具备 Robust 爬虫能力，支持多 UA 轮换、自动重试、GB18030 编码处理及 Trade500 备用源高成功率抓取。 |
| **世界杯人格测试** | `PersonalityService` 支持 12 题 12 人格的完整逻辑，包含 80+ 条副标题梗文案、战力指数计算及稀有度判定。 |

| --- | --- | --- |

## 部署与运维

### 自动部署

代码推送到 `main` 分支后，GitHub Actions 会自动部署到生产服务器。部署脚本 `deploy/production/ai-worldcup-deploy.sh` 已更新 `PUBLIC_SITE_URL` 默认值和 Nginx 域名配置。

### 数据库更新

若更新了人格测试文案或题目，需在服务器执行：
```bash
pnpm prisma db seed
```

## Roadmap / 未来增强

1. **多维度战绩分析**：基于多结果预测数据，提供更精细的模型胜率统计（如：单选胜率 vs 多选胜率）。
2. **AI 研判置信度**：基于模型间的一致性，自动生成预测置信度分值。
3. **Lindy 异步流优化**：进一步缩短 Lindy 回调到前端展示的延迟。
